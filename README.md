# order_analysis

Проект для анализа заказов: обработка CSV-файлов, выявление ошибок и формирование отчётов.

## Структура проекта

- `src/` — исходный код 
- `data/` — тестовые данные (нормальные и с ошибками)
- `logs/` — ошибки при обработке
- `reports/` — итоговые отчёты

## Как запустить

1. Установите зависимости: `pip install -r requirements.txt`
2. Запустите проект: `python run.py`
